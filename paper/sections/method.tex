\section{Method: Probe Prompting and a Matched-Control Causal-Validation Harness}
\label{sec:method}

\subsection{Setting and attribution-graph generation}
\label{sec:method:setting}
We use Gemma-2-2B-it with the public CLT-HP dictionary ($\sim$2.5M features over 26 layers; \citealp{ameisen2025circuittracing}). Attribution graphs are generated via the Neuronpedia API with \texttt{nodeThreshold}=0.8, \texttt{edgeThreshold}=0.85, \texttt{maxFeatureNodes}=5000. The feature universe $V_p^{\tau}$ is selected by cumulative-influence threshold $\tau{=}0.95$ for batch experiments. The replacement model freezes attention during graph computation; downstream interventions (\cref{def:swap}) run with attention free, making positive results harder than under frozen attention~\cite{ameisen2025circuittracing}.

\subsection{Cross-Prompt Activation Signatures (CPAS)}
\label{sec:method:cpas}
For each (feature, probe) pair we record raw measures (peak token, peak position, activation density, sparsity ratio, robust $z$, cosine to seed). Aggregating across probes yields the CPAS used by the decision tree below: \texttt{peak\_consistency\_main}, \texttt{n\_distinct\_peaks}, \texttt{func\_vs\_sem\_pct}, \texttt{share\_F}, \texttt{sparsity\_median}, \texttt{conf\_S}. Formal definitions are deferred to \cref{appx:pipeline}.

\subsection{Functional vs.\ semantic tokens; target-token mapping}
\label{sec:method:funcsem}
Tokens are labeled \emph{functional} (copulas, articles, prepositions, conjunctions, relative pronouns, auxiliaries; $\sim$87 English tokens) or \emph{semantic} (content-bearing). When a feature peaks on a functional token, a $\pm 7$-token directional search identifies the nearest semantic target (forward for \texttt{is}/\texttt{are}/articles/most prepositions; backward for \texttt{of}/possessive \texttt{'s}; bidirectional for conjunctions/punctuation). Full vocabulary, edge cases, and a documented French-prompt failure mode are in \cref{appx:funcvocab}.

\subsection{Transparent classification rules}
\label{sec:method:rules}
Feature classification uses the strict-priority decision tree below; the first matching rule wins. Pseudocode and threshold derivations are in \cref{appx:pipeline}.

\begin{itemize}\itemsep0pt
  \item \textsc{Sem-Dict}: \texttt{peak\_consistency\_main}$\geq 0.80$ \textsc{and} \texttt{n\_distinct\_peaks}$\leq 1$.
  \item \textsc{Say-X}: \texttt{func\_vs\_sem\_pct}$\geq 50$ \textsc{and} \texttt{conf\_F}$\geq 0.90$ \textsc{and} layer $\geq 7$.
  \item \textsc{Rel}: \texttt{sparsity\_median}$<0.45$.
  \item \textsc{Sem-Conc}: layer $\leq 3$ \textsc{or} \texttt{conf\_S}$\geq 0.50$ \textsc{or} \texttt{func\_vs\_sem\_pct}$<50$.
  \item \textsc{Review}: otherwise (manual inspection, excluded from analysis).
\end{itemize}

We chose rules rather than a learned classifier because the grouping itself is the object of interpretability research. Rules give traceability (every assignment maps to specific threshold crossings), debuggability, editability, and communicability---properties a learned grouper would lose.

\subsection{Supernode formation and naming}
\label{sec:method:supernodes}
Same-rule same-name features form a supernode (\cref{def:supernode}). Cross-prompt stability is enforced ($\geq 60\%$ of probes); features failing this are marked \emph{ungrouped} (5--10\% of candidates) and excluded. Naming policy: strongest semantic peak for \textsc{Sem-Dict}/\textsc{Sem-Conc}; discovered target token for \textsc{Say-X}; aggregated activation over an extended vocabulary for \textsc{Rel} (format ``(token) related''). A configurable blacklist filters uninformative names.

\subsection{Pipeline output: compression with high coverage}
\label{sec:method:compression}
The pipeline output is a property of the method, not a claim being tested: concept-aligned subgraphs compress 600$+$ raw features into 30--50 named supernodes per circuit while preserving Neuronpedia \emph{Completeness} (mean 0.83 over five circuits) and accepting a \emph{Replacement} drop to 0.54 (\cref{tab:graph-subgraph}). The trade-off is intentional: low-influence nodes are treated as error to maximize legibility. We report this here so the reader knows the unit of analysis (supernodes, not raw features) before \cref{sec:results} introduces interventions.

\subsection{Causal-validation harness}
\label{sec:method:harness}

\paragraph{Intervention mechanism.}
Additive delta injection via CLT decoder vectors (\cref{def:swap}). For each intervened feature, $v_{\mathrm{new}} = M \cdot v_{\mathrm{orig}}$ scales the decoder vectors and adds the result to the residual stream at downstream layers. Defaults: $M_{\mathrm{ablate}}{=}-2$, $M_{\mathrm{amplify}}{=}20$. \emph{Attention is not frozen} during intervention; positive results are stronger evidence than under frozen-attention patching where some direct effects are forced by construction~\cite{ameisen2025circuittracing}.

\paragraph{Matched random control (\cref{def:matched}).}
This is the central methodological move and replaces the geometric-baseline comparison. The control fixes feature count and per-layer histogram and excludes \emph{all} concept-aligned supernodes from the sampling pool, so the only varying property is concept alignment. Three deterministic replicates per pair give Hit-rate and vsMax distributions over random feature sets. The protocol is grouping-method-agnostic and can be re-run on any competing grouping.

\paragraph{Field-additivity decomposition.}
Each domain has 3 semantic fields (input, intermediate, answer; \cref{tab:domains}). For each pair, 7 variants are run: 3 single-field, 3 two-field, 1 all-three. Each selected field drives both ablation and amplification; this isolates which fields carry the causal signal.

\paragraph{Adaptive $M$-search.}
Two-phase post-hoc search for $M_{\mathrm{amplify}}$ on missed pairs. Phase~1: 6-point geometric probe on $[0.1, 20]$, stopping at the first hit. Phase~2 (if no Phase~1 hit): KL-transition binary refinement around the steepest KL transition, 6 steps. Applied to labeled and field-additivity runs (1{,}210 + 867 eligible pairs; full pseudocode in \cref{appx:msearch}).

\subsection{Metrics}
\label{sec:method:metrics}
\textbf{Primary} (per \cref{def:hit}): \textbf{Hit\%}, \textbf{vsMax}, \textbf{Target Recovery} (target logit beats its own unsteered baseline at any trajectory position).
\textbf{Supporting:} Sup\% (source absent from output), RkGrp (best target rank within the domain answer set), Flip\% (target--source rank crossover), CtrlS (mean absolute logit shift of control tokens), KL$(\mathrm{baseline} \| \mathrm{steered})$ at position 0.
We deliberately do \emph{not} use gap-closure as a primary metric (regime-dependent and confounded by baseline gap; see \cref{appx:gapcl}). We report both position-0 and best-over-trajectory variants; the two diverge in informative ways across domains (\cref{appx:pos0}).
