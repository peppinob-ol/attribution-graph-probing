\section{Experimental Design}
\label{sec:expdesign}

\subsection{Domains and seed prompts}
\label{sec:expdesign:domains}
We evaluate on four domains spanning two-hop factual recall in different relational structures and answer geometries. Each domain has a fixed seed-prompt template with three semantic fields (input, intermediate, answer): USA (``capital of state containing $X$''; 50 entities, 2{,}450 non-identity swap pairs, answer-set size $K{=}50$), Books (``character $X$ from book by''; 10/90/25), Products (``product $X$ from company by''; 12/132/25), and Paintings (``painting $X$ by painter''; 10/90/20).

\subsection{Experimental matrix}
\label{sec:expdesign:matrix}
Each swap pair is run under: (a) labeled (3-field) baseline at $M{=}20$; (b) matched random control (3 replicates per pair); (c) field-additivity (7 variants per pair); (d) adaptive $M$-search on labeled and on the best field-add variant per missed pair. The total is \textbf{41{,}784 swap runs} across all conditions, domains, and $M$ values.

\subsection{Pre-registered evaluation choices}
\label{sec:expdesign:prereg}
Before running the sweep we fixed the evaluation protocol. The contrast set used by vsMax is the set of all other dataset answers in the same domain, and multi-token answers are resolved to their first subword so that Hit is a deterministic substring check. Intervention and measurement are explicitly decoupled: the intervention operates on supernodes tied to entity fields, while the Hit/vsMax readout is always taken on the answer field. Generation uses temperature $0.3$, a maximum of 10 new tokens, a frequency penalty of $2.0$, and a fixed seed; matched-control replicates are drawn with sha256-based seeding from the run seed and pair identifier. At the pair level we count a random-hit if any of the three matched-control replicates is a hit, so the random baseline is deliberately optimistic. Ranges, thresholds, and seeds were frozen prior to the 41{,}784-run sweep. Full details are in \cref{appx:pipeline}.
