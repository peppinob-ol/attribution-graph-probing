\section{Results}
\label{sec:results}

\paragraph{Experimental setup}
We evaluate on Gemma-2-2B-it using cross-layer transcoders (CLTs) as our feature dictionary. CLTs read from the residual stream at each layer and jointly reconstruct MLP outputs downstream, trained with JumpReLU activations and an explicit sparsity penalty. For Gemma-2 (2B), a published CLT suite contains ~2.5M features in total, which we use to build local replacement models and attribution graphs. Prompt families span multiple domains to test generalization beyond single-circuit artifacts:

\begin{itemize}
  \item Geographic knowledge: ``The capital of Texas is'' $\rightarrow$ Austin (Dallas variant), ``The capital of California is'' $\rightarrow$ Sacramento (Oakland variant)
  \item Sports entities: ``Michael Jordan plays'' $\rightarrow$ Basketball  
  \item Semantic opposition: ``The opposite of small is'' $\rightarrow$ large
  \item Anatomical relations: ``The muscle called the diaphragm''
\end{itemize}

Each circuit uses Neuronpedia's attribution graph generation with replacement model (freezing attention patterns, layer norms). We select features via cumulative influence threshold ($\tau = 0.60$--0.80, chosen to capture top 70--80\% of influence). Probe prompts generated via Claude-3.5-Sonnet with temperature 0.7, manually reviewed for quality (rejecting semantically identical or syntactically malformed prompts). Activation measurements via Neuronpedia API (approximately 10--15 minutes on L4 GPU for 5 probes $\times$ 40 features). All experiments use fixed random seeds.

\paragraph{Interpretation (C2: Interpretability-Oriented Compression)}
These results support our second claim that behavioral grouping enables interpretability-oriented compression. Completeness remains high (mean 0.83 vs 0.90 for full graphs, $\Delta = -0.07$), indicating concept-aligned subgraphs capture most incoming edge influence to nodes: the subgraph is largely self-contained with few unexplained inputs. Replacement drops more substantially (mean 0.54 vs 0.70, $\Delta = -0.16$), reflecting our deliberate choice to exclude low-influence nodes that contribute little to functional understanding but would inflate raw coverage.

This trade-off is intentional and aligns with interpretability goals. We prioritize legibility (30--50 interpretable supernodes with semantic labels) over exhaustive coverage (600+ unlabeled features). Replacement is computed against full end-to-end influence from input embeddings to target logit; unpinned nodes are treated as error, so lower Replacement indicates higher abstraction rather than lost explanatory power. A perfectly complete subgraph (Replacement = Completeness = 1.0) would be the full raw graph---maximally comprehensive but minimally interpretable.

The consistent 79--86\% Completeness across all five prompts, despite varying Replacement scores (0.45--0.62), indicates that concept-aligned grouping successfully identifies features that explain model behavior, even when the simplified circuit doesn't fully replicate it. This trade-off---interpretability vs.\ completeness---is acceptable for circuit analysis purposes where understanding causal structure matters more than perfect reconstruction.

\paragraph{Interpretation (C1: Behavioral Coherence)}
These results support our first claim that concept-aligned grouping exhibits higher behavioral coherence than geometric clustering. Peak-token consistency (0.425 vs 0.183 for cosine, 2.3$\times$ improvement) indicates concept-aligned features activate on the same tokens far more reliably across probes: 42.5\% of features in a supernode peak on identical tokens, compared to 18.3\% for cosine-clustered features. Activation-pattern similarity (0.762 vs 0.130 for cosine, 5.8$\times$ improvement) indicates higher within-group activation vector correlation: features in a behavioral supernode respond similarly across contexts, while cosine-clustered features may be geometrically close but functionally diverse.

The trade-off is geometric compactness: concept-aligned grouping scores lower on Silhouette index (0.124 vs 0.707 for layer-adjacency), indicating groups are not spatially compact in activation vector space or layer-influence graph. This is expected and desirable: functional roles (semantic detection, relationship binding, output promotion) can span multiple layers and diverse activation patterns. Layer-adjacency clustering trivially achieves high Silhouette by grouping nearby layers, but this reflects geometric proximity rather than shared function---adjacent-layer features may perform unrelated computational roles.

Davies-Bouldin scores are comparable across methods (1.30 vs 1.58/0.49), suggesting reasonable within-group cohesion despite cross-layer membership. Sparsity consistency (0.255) is lower than baselines (0.335--0.399), indicating concept-aligned features concentrate activation on fewer tokens (lower is better for this metric). This aligns with the Say-X category: output promoters should activate sparsely on functional tokens, not diffusely across all tokens.

Important caveat: Neuronpedia Replacement/Completeness scores are near-invariant across the three methods (all pin the same 39 nodes) and thus do not discriminate grouping quality. The behavioral metrics above provide the actual comparison. Results are descriptive from a single circuit; broader validation needed.

\paragraph{Interpretation (C3: Early-vs-Late Hierarchy)}
These results support our third claim of a layerwise computational hierarchy. Features that transfer from Dallas$\rightarrow$Austin to Oakland$\rightarrow$Sacramento (64\%, 25/39 features) come from significantly earlier layers (mean 6.3, SD 5.2) than features that fail to transfer (mean 16.4, SD 5.8). The layer difference ($\Delta = 10.1$ layers, approximately 40\% of the model's 26 layers) is substantial and consistent with a two-stage computation: early layers encode transferable relational structure (`X is the capital of Y'), late layers specialize for specific output tokens (`say Austin' vs `say Sacramento').

Transferred features show perfect behavioral consistency when substituting entities: 96\% peak on the appropriate capital for the new entity (Oakland features peak on `Sacramento', not `Austin'; Dallas features peak on `Austin', not `Sacramento'). Activation overlap is 1.000 (SD 0.000), indicating transferred features' activation patterns are identical (within numerical precision) across entity swaps after accounting for entity-token substitution. This validates that transfer captures genuine functional equivalence, not spurious token overlap.

The 64\% transfer rate is descriptive and derives from a single circuit pair. We interpret this as proof-of-concept evidence for hierarchical computation, not definitive characterization. Replication across additional entity pairs (e.g., Paris$\rightarrow$France, London$\rightarrow$England) would strengthen generality claims. Follow-up work testing whether non-geographic circuits (arithmetic, code generation) exhibit similar early-vs-late split would assess whether this is a domain-general principle or specific to factual recall tasks.

\paragraph{Compositional analysis}
Examining feature categories, transferred features are predominantly Semantic (entity detectors: `capital', `state', `containing') and Relationship (`capital-of' relation, copula binding). Failed-transfer features are predominantly Say-X (`Say Austin', `Say Texas') concentrated in layers 14--18. This categorical separation supports the backbone-and-specialization model: early layers build task-general representations (entity detection, structural binding), late layers shape output distribution (token promotion, probability allocation).
