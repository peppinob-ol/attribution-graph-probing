\begin{abstract}
%Attribution graphs expose the circuits underlying a language model's output, but a single graph for a short factual prompt routinely contains thousands of cross-layer transcoder features and takes on the order of two hours to interpret by hand. Existing automated interpretation methods label individual features from corpus activations, yet they do not produce circuit-level groupings calibrated to a target logit, and the labels are not validated by causal intervention. We introduce \emph{probe prompting}, a transparent rule-based pipeline that groups the features of an attribution graph into concept-aligned supernodes from their responses on a small set of concept-targeted probe prompts, summarized as Cross-Prompt Activation Signatures (CPAS). A supernode label is \emph{operationally useful} when intervening on the labeled supernode redirects the generated output toward the target concept (Specificity) and a structurally matched random feature set fails to do so (Matched-Control). Across four factual domains on Gemma-2-2B-it with the public CLT-HP dictionary and $41{,}784$ entity-swap interventions, labeled supernodes satisfy both conditions in every domain (USA vsMax gap $+5.17$, Books $+6.13$, Products $+3.23$, Paintings $+1.58$ logits against matched random at default intervention settings). Secondary analyses on the same runs account for why default interventions sometimes miss: restricting the intervention to the intermediate and answer fields raises Hit-rate by $9$--$33$ percentage points in three of four domains, and an adaptive multiplier search shows that the $M{=}20$ default inherited from single-feature steering overshoots in the multi-feature regime, with most rescued pairs accepting $M$ in $[2, 7]$. Code, datasets, and an interactive demo are released anonymously as a reusable harness for calibrating supernode labels against causal interventions.

Even though we know the precise computations that lead from a large language model (LLM) input to its output this computation remains very hard to interpret. One way to make it easier to understand this process is by creating a sparse computational graph that captures most of the model behavior with smallest number of computational nodes. Cross-layer transcoders (CLT) decompose the dense computations of the MLP but the resulting circuits still contain thousands of nodes even for short prompts. Existing automated interpretation methods label individual features from corpus activations, and it often happens that these labels are not validated by causal intervention. We introduce \emph{probe prompting}, a transparent rule-based pipeline that groups the features of an attribution graph into concept-aligned supernodes from their responses on a small set of concept-targeted probe prompts, summarized as Cross-Prompt Activation Signatures (CPAS). Across four factual domains, on Gemma-2-2B-it with a public CLT-HP dictionary and $41{,}784$ entity-swap interventions, we find that the labeled supernodes have the predicted steering behavior in every one of them.
Code, datasets, and an interactive demo are released anonymously as a reusable harness for calibrating supernode labels against causal interventions.
\end{abstract}
